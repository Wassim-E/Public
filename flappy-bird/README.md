# 🐦 Flappy Bird PWA

A fully functional Flappy Bird game that works as a Progressive Web App (PWA) for phone installation.

## Features

- **Full Flappy Bird gameplay** with physics and collision detection
- **Progressive Web App** - Installable on phones (iOS & Android)
- **Offline support** - Play without internet connection
- **Responsive design** - Works on all screen sizes
- **High score tracking** - Saves your best score locally
- **Touch controls** - Optimized for mobile play

## How to Install on Phone

### Android:
1. Open the game in Chrome
2. Tap the menu button (⋮)
3. Tap "Install App" or "Add to Home Screen"
4. Confirm installation

### iOS:
1. Open the game in Safari
2. Tap the share button (📤)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add" in the top right

## Game Controls

- **Tap anywhere** or press **Spacebar** to make the bird flap
- Avoid the pipes to score points
- Each pipe passed = 1 point

## Development

This is a static web app built with:
- HTML5 Canvas for graphics
- Vanilla JavaScript for game logic
- Service Worker for offline functionality
- Web App Manifest for PWA installation

## Files

- `index.html` - Main HTML file
- `style.css` - Styling and responsive design
- `game.js` - Game logic and rendering
- `pwa.js` - PWA installation functionality
- `sw.js` - Service Worker for offline support
- `manifest.json` - PWA manifest
- `icon-192.png` / `icon-512.png` - App icons
